# GitHub Repo Summary Tool
A command-line tool that takes any GitHub username and prints a short report of:
1. All of the user's public repos (no forks i.e. copies of other people's projects)
2. Each repo, followed by it's stars, languages used, language most used, and the last-updated date
3. Count of how many repos use each language
4. The top 5 repos, from the one with the most stars
